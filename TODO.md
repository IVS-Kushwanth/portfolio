# Deployment to Vercel (Static)

- [ ] Verify project root contains `index.html`, `styles.css`, `script.js`, `assets/`, and `AI_resume.pdf`.
- [ ] Create a Vercel project and connect/import from GitHub (or upload the folder).
- [ ] Set Vercel framework preset to **Static** / no build command.
- [ ] Deploy and open the Vercel preview URL.
- [ ] Verify assets and resume PDF load (no 404s).
- [ ] (Optional) Add custom domain and enable HTTPS.
