# Portfolio Website 🚀

A modern, fully responsive portfolio website to showcase your web development skills.

## 📁 Files Structure

- `index.html` - Main HTML file with all sections
- `styles.css` - Complete styling and responsive design
- `script.js` - JavaScript for interactivity and animations

## 🎨 Features

✅ **Responsive Design** - Works perfectly on desktop, tablet, and mobile
✅ **Smooth Animations** - Engaging scroll animations and transitions
✅ **Mobile Menu** - Hamburger menu for mobile devices
✅ **Social Media Integration** - Easy links to Gmail, LinkedIn, and GitHub
✅ **Projects Showcase** - Beautiful project cards with descriptions
✅ **Professional Styling** - Modern gradient design with color scheme
✅ **SEO Friendly** - Proper semantic HTML structure

## 🎯 Sections

1. **Navigation Bar** - Sticky navbar with smooth scrolling
2. **Hero Section** - Eye-catching landing section
3. **About Me** - Your professional bio
4. **Connect (Social Media)** - Gmail, LinkedIn, GitHub links
5. **Projects** - Showcase your work with descriptions and links
6. **Footer** - Footer with credits

## 🛠️ How to Use

### 1. **Update Social Media Links**
In `index.html`, find the Social Media Section and update:
- Gmail: Replace `your-email@gmail.com` with your actual email
- LinkedIn: Replace `https://linkedin.com` with your LinkedIn profile URL
- GitHub: Replace `https://github.com` with your GitHub profile URL

### 2. **Open in Browser**
Simply open `index.html` in your web browser. No server needed!

```bash
# On Windows, you can double-click index.html or:
start index.html
```

## 🎨 Customization Tips

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;      /* Main color */
    --secondary-color: #764ba2;    /* Secondary color */
    --text-color: #2d3748;         /* Text color */
}
```

### Add More Projects
Duplicate the project card HTML in the Projects Section for more projects.

### Update Footer
Change the footer text in the last `<section>` tag in `index.html`.

## 📱 Responsive Breakpoints

- Desktop: Full layout (1200px+)
- Tablet: Adjusted grid (769px - 1199px)
- Mobile: Single column (480px - 768px)
- Small Mobile: Optimized for tiny screens (<480px)
